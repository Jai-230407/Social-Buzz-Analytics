# Data Visualisation Virtual Experience Program

## 📌 Overview
This repository contains my work completed as part of the **Tata Group Data Visualisation: Empowering Business with Effective Insights Virtual Experience Program** on Forage.

The project focuses on transforming business data into meaningful visual insights to support executive decision-making. Using Power BI, I created interactive dashboards and presented recommendations based on customer and revenue trends.

---

## 🎯 Objectives
- Analyze business data to identify key trends and performance indicators.
- Build interactive dashboards for executive-level reporting.
- Communicate insights through effective data storytelling.
- Recommend business strategies based on data-driven findings.

---

## 🛠️ Tools & Technologies
- **Power BI**
- Microsoft Excel

## 📊 Project Tasks

### Task 1 – Business Scenario
- Understood business requirements from executive stakeholders.
- Identified KPIs relevant for strategic decision-making.

### Task 2 – Data Cleaning & Preparation
- Explored and cleaned transactional datasets.
- Handled missing values and inconsistent records.
- Prepared data for visualization.

### Task 3 – Dashboard Development
Developed interactive dashboards including:
- Revenue Analysis
- Customer Segmentation
- Monthly Sales Trends
- Country-wise Performance
- Top Customers Analysis

### Task 4 – Business Insights
Generated actionable insights such as:
- High-performing markets and customers.
- Revenue contribution across regions.
- Seasonal sales trends.
- Business opportunities for growth.
